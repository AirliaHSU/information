服務方案

先選一個最接近的方向即可（只有初步想法也沒關係）。我會在 2 個工作天內回覆可行方案、時程與報價區間。

方案 A
2D 動畫製作（已提供腳本 / 分鏡）

適合已有文案/腳本或分鏡的團隊，直接進入動畫製作。

  • 動畫製作（節奏／轉場／動態視覺）
  • 素材整理與畫面一致性調整
  • 成品輸出（MP4，常用比例）
不含：腳本撰寫／分鏡設計
方案 B
分鏡設計 + 2D 動畫（從概念到成片）

適合只有大綱或初步想法，需要協助整理資訊與畫面節奏。

  • 內容拆解與節奏規劃
  • 分鏡設計（畫面安排／運鏡節奏）
  • 2D 動畫製作與輸出（MP4）
不含：配音錄製／上架投放操作
方案 C
LOGO 動畫（Logo Reveal / 動態識別）

適合品牌片頭、社群短片片尾或活動開場使用。

  • LOGO 動態設計（簡潔／光影／節奏型）
  • 輸出版本：MP4（可加購透明背景）
  • 常用比例需求（16:9 / 1:1 / 9:16）
不含：LOGO 原始設計（需提供向量或清晰檔）
